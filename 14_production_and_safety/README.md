# 14 - Production & Safety ⏳

🔗 **Pichle chapters se connection:** Bot ban gaya aur test bhi ho gaya. Ab use dusron ke liye **live** karna hai, aur **safe** bhi rakhna hai.

## Kya seekhenge
- AI ko API banana (**FastAPI**)
- Simple web UI (**Streamlit / Gradio**)
- Streaming, caching, rate limits, **cost** control
- Local model vs cloud API (OpenAI, Claude): switch kaise karein
- **Prompt injection** & **guardrails**
- Secrets aur user data ki privacy

## 🌍 Real world
- 2023 mein ek car dealership ke chatbot ko users ne trick karke **$1 mein car bechne** pe "agree" karwa liya. Isliye guardrails zaroori hain.
- Har AI company ko rate limits aur cost limits lagani padti hain
