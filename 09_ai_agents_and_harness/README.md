# 09 - AI Agents & Harness ⏳

🔗 **Chapter 08 se connection:** Ek tool call se aage: AI **khud plan kare** aur kai steps mein tools use kare, jab tak kaam pura na ho jaaye.

## Kya seekhenge
- **Agent = LLM + Tools + Loop**
- **Agent loop (ReAct)**: Think → Act → Observe → repeat
- **Harness**: model ke around ka poora system: loop, tools, memory, context management, permissions, guardrails.
  Model = engine, harness = poori car 🚗
- Planning, multi-agent basics
- Agents kab fail hote hain (infinite loop, galat tool, context bhar jaana)

## 🌍 Real world
- **Claude Code, Cursor**: coding agents, harness ka best example (files padhna, code likhna, commands chalana)
- Browser agents jo website pe khud click karke kaam karte hain
- Support agents jo khud refund process kar dete hain
