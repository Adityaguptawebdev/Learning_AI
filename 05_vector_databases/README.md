# 05 - Vector Databases ⏳

🔗 **Chapter 04 se connection:** Embeddings bana liye. Par jab lakhon ho jaayein, to Python list mein search karna slow ho jaata hai. **Vector DB** embeddings ko store aur fast search karne wala special database hai.

## Kya seekhenge
- Normal DB vs Vector DB: kyun alag chahiye
- **ChromaDB** (local, free): add, query, delete
- **Metadata & filters**: "sirf 2024 ke documents mein search karo"
- **Index (HNSW)**: fast "approximately best" search, simple samjhaai
- Popular DBs: Pinecone, Qdrant, Weaviate, Milvus, pgvector, FAISS

## 🌍 Real world
- Shopping sites pe "similar products"
- Notion / Slack AI search, jo saare documents mein meaning se dhoondhta hai
- Photo se search (Google Lens types)
