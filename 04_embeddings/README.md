# 04 - Embeddings ⏳

🔗 **Pichle chapters se connection:** LLM text samajhta hai. Par computer do sentences ka **meaning** compare kaise kare? Text ko numbers mein badal ke. Isi se Phase 2 (AI ko apna data dena) shuru hota hai.

## Kya seekhenge
- **Embedding**: text → numbers ki list (vector), jo text ka meaning pakadti hai
- Similar meaning = vectors paas-paas
- **Cosine similarity**: do vectors kitne milte hain
- **Semantic search vs keyword search**
- Ollama embedding model: `nomic-embed-text`

## 🌍 Real world
- Google samajh jaata hai ki "sasta phone" aur "budget smartphone" same cheez hai
- Netflix / Spotify recommendations ("aapko ye bhi pasand aayega")
- Quora / Stack Overflow pe duplicate questions pakadna
