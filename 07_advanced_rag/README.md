# 07 - Advanced RAG ⏳

🔗 **Chapter 06 se connection:** Basic RAG kabhi galat tukda la deta hai ya sahi tukda miss kar deta hai. Ab quality badhayenge.

## Kya seekhenge
- **Chunking strategies**: size, overlap, heading ke hisaab se todna
- **Hybrid search**: keyword (BM25) + vector, dono saath
- **Re-ranking**: mile hue results ko dobara sahi order mein lagana
- **Query rewriting**: user ka sawal search ke liye behtar banana
- **Citations**: jawab ke saath source batana
- RAG fail kyun hota hai, aur kaise debug karein
